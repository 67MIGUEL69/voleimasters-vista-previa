# Vista prèvia de Voleimasters

Aquesta còpia es genera sola a cada canvi. **No editis res aquí**:
el codi viu en un altre repositori i qualsevol canvi fet en
aquest es perdrà a la publicació següent.

Porta una fotografia de les dades a dins i funciona sense
servidor: els marcadors surten congelats, no hi ha avisos i el
que s'hi toqui no surt del navegador.
